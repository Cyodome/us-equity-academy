### 12-1 米国株口座で確認すべき項目

証券会社によって、米国株の手数料体系・取引時間・注文タイプ・情報機能は大きく異なる。口座を選ぶとき、また既に持っている口座を使い続けるときも、以下の項目を公式サイトとアプリ内の表示で確認する。手数料やサービス内容は改定されるため、年に一度は再確認する。

| 項目 | 確認する内容 | 投資判断への影響 |
|---|---|---|
| 取引手数料の体系 | 約定代金に対する比率（上限額付き）か、取引株数ベースか。少額約定の無料枠の有無 | 月10万円程度の積立では比率型が有利なことが多い。多株数の取引では株数ベースが有利になりうる |
| 為替手数料 | 円→ドルの片道コスト。無料か、1ドルあたり数銭〜数十銭か | 毎月の積立で往復発生するため、長期では取引手数料以上に効く |
| 円貨決済の可否 | 円のまま米国株を買えるか（自動でドル転） | 手間と為替タイミングの悩みを減らす |
| 取扱銘柄数 | 米国株・ETFの本数。ADRの取り扱い | 第II部で選んだ銘柄が買えるか |
| 取引時間 | 本場のみか、プレ・アフター・夜間（24時間）取引に対応しているか | 日本の日中に発注・約定できるかが変わる（第13章5節） |
| 注文タイプ | 成行・指値・逆指値・逆指値指値・トレーリングストップ・OCOの対応 | 第13章のシーン別戦略が実行できるか |
| 有効期限 | 当日のみか、期間指定（GTC）の上限日数 | 押し目待ちの指値を置けるか |
| NISA対応 | 成長投資枠で米国株・ETFを買えるか。NISA対象外銘柄の表示が正確か | 第1章4節の非課税効果 |
| 自動積立 | 米国株・ETFの定期買付に対応しているか。投資信託のみか | 第15章のルーチンを自動化できるか |
| 少額投資 | 1株未満（端株）の買付に対応しているか | 高株価ETFを毎月定額で無駄なく買えるか |
| 情報機能 | 財務データ、スクリーナー、機関投資家の保有動向、アナリスト評価、決算カレンダー、アラート | 12-3節 |
| デモ取引 | 仮想資金での練習機能の有無 | 12-5節 |
| 安全性 | 分別管理、投資者保護基金の対象、金融商品取引業の登録、行政処分歴 | 資産の保全。金融庁・財務局の公表資料で確認できる |

### 12-2 口座区分の選び方

| 口座区分 | 課税 | 確定申告 | 適した用途 |
|---|---|---|---|
| 特定口座（源泉徴収あり） | 売却益・配当から自動で源泉徴収 | 原則不要（外国税額控除を受ける場合は必要） | 初心者の基本。NISA枠を超える保有分 |
| 特定口座（源泉徴収なし） | 年間取引報告書をもとに自分で申告 | 必要 | 他の所得と合わせて申告する人 |
| 一般口座 | 損益計算も自分で行う | 必要 | 特殊な事情がある場合のみ |
| NISA口座（成長投資枠） | 売却益・配当の日本分が非課税 | 不要 | 長期保有するETF・優良株を優先配分（第1章4節） |

### 12-3 情報機能と第II部の指標の対応

証券会社のアプリ・取引ツールには、第II部で扱った指標をそのまま検索・比較できる機能が備わっていることが多い。

| 機能 | 内容 | 第II部との対応 |
|---|---|---|
| 財務データ（銘柄詳細） | 損益計算書・貸借対照表・キャッシュフロー計算書の四半期・年次推移 | 第4章〜第9章の全指標の一次データ |
| バリュエーション指標 | PER・PBR・PSR・EV/EBITDA・配当利回りの現在値と履歴 | 第5章の自社履歴比較（過去5〜10年レンジ） |
| スクリーナー | 財務・バリュエーション・テクニカルの条件で銘柄を絞り込み | 第11章5節の判断フローチャートを条件化して実行 |
| 機関投資家の保有動向 | 大手運用会社・著名投資家の保有・売買履歴（米SECへの13F報告に基づく） | 質の高い投資家の判断を参照。ただし追随ではなく検証材料 |
| アナリスト評価 | 目標株価の分布、レーティング、コンセンサスEPS予想 | 第4章4節のコンセンサス把握 |
| 決算カレンダー | 保有・監視銘柄の決算日と予想 | 第13章のイベント前後の注文管理 |
| ヒートマップ | 市場全体・セクター別の騰落を色で表示 | 相場環境の把握（第14章） |
| アラート | 株価・出来高・ニュースの条件通知 | 第11章8節の早期警戒サインの検知 |
| 板情報・歩み値 | 気配値の数量と約定履歴 | 第13章1〜3節 |
| 学習コンテンツ | 動画・記事による基礎解説 | 本書と併読 |

**スクリーナーに第11章の判断基準を設定する例**

| 目的 | 条件（例） | 対応節 |
|---|---|---|
| バリュー候補の抽出 | ROE ≧ 15%、自己資本比率 ≧ 40%、予想PER ≦ 20倍、FCF利回り ≧ 5%、時価総額 ≧ 100億ドル | 11-2 |
| グロース候補の抽出 | 売上成長率 ≧ 25%、粗利率 ≧ 70%、時価総額 ≧ 50億ドル | 11-3 |
| インカム候補の抽出 | 配当利回り ≧ 2.5%、配当性向 ≦ 60%、連続増配 ≧ 10年、純有利子負債/EBITDA ≦ 2倍 | 11-4 |

スクリーナーは「候補の抽出」までであり、抽出後は第II部の手順（データシートの作成、DCF、ストレステスト）で個別に検証する。証券会社が提供する財務データは、決算修正や会計基準の違いで一次資料（10-K）と食い違うことがあるため、投資額が大きい銘柄は必ず10-Kで再確認する（第11章9節）。

### 12-4 決算・イベント管理の運用

| 運用 | 手順 |
|---|---|
| 決算日の把握 | 保有・監視銘柄をウォッチリストに登録し、決算カレンダーで日付を確認。日本時間では早朝（引け後発表）または夜（寄付き前発表） |
| 決算資料の確認順序 | 第11章9節の順序（実績とコンセンサスの差 → ガイダンス → キャッシュフロー → 貸借対照表 → Q&A → 株式数） |
| アラート設定 | 保有銘柄に「株価▲10%」「出来高3倍」のアラートを設定し、第11章8節の警戒サインを検知 |
| 記録 | 決算ごとに、第II部のスコアカード（11-1）を更新し、投資テーゼの継続・崩壊を判定 |

### 12-5 デモ取引の使い方

実資金を投じる前に、デモ取引で次の点を確認する。第13章の注文タイプは、実際に発注して約定の挙動を見るのが最も理解が早い。

| 確認項目 | 内容 |
|---|---|
| 注文タイプの挙動 | 指値・逆指値・トレーリングストップ・OCOを実際に発注し、どの条件で約定・失効するかを確認 |
| セッションの違い | プレマーケット・本場・アフター・夜間で、スプレッドと約定のしやすさがどう違うかを観察 |
| 決算日の値動き | 決算発表当日の寄付き前後の価格変動幅と、逆指値がどこで約定するかを体験 |
| 板の動き | 寄付き直後・引け前・指標発表直後に板の数量とスプレッドがどう変化するかを観察（第13章2節） |

> **投資判断への直結**
> - 手数料・為替コスト・注文タイプ・取引時間・NISA対応を公式情報で確認し、年に一度は再点検する。
> - 財務データ・バリュエーション履歴・スクリーナーで第II部の指標を検索し、候補抽出後は10-Kで個別に検証する。
> - 決算カレンダーとアラートで、テーゼの継続・崩壊を四半期ごとに判定する体制を作る。
> - 注文タイプと板の挙動はデモ取引で確認してから実資金で使う。
